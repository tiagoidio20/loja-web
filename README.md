# SuperTech Store

Loja web simples de informática, feita com HTML e CSS.

O layout usa **somente Flexbox** (sem Grid, float ou position para posicionar).

## Como usar

Abra o arquivo `index.html` no navegador.

## Arquivos

- `index.html` – estrutura da página (cabeçalho, banner, vantagens, produtos, sobre/oferta, rodapé)
- `style.css` – estilos com Flexbox e responsividade
